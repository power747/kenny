# 할 일 목록 (TODO App)

설치나 빌드 없이 브라우저에서 바로 실행되는 간단한 TODO 앱입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## 기능

- 할 일 추가 (선택적으로 마감일 지정)
- 완료 체크 / 모두 완료
- 더블클릭으로 제목 수정 (Enter 저장, Esc 취소, 비우면 삭제)
- 항목 삭제, 완료 항목 일괄 삭제
- 전체 / 진행 중 / 완료 필터
- 마감일 표시: 오늘까지, 내일까지, 기한 지남 강조
- `localStorage`에 자동 저장, 여러 탭 간 동기화
- 시스템 설정에 따른 다크 모드, 모바일 화면 대응

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 마크업 |
| `style.css` | 스타일 (라이트/다크 테마) |
| `app.js` | 상태 관리, 렌더링, 이벤트 처리 |
